Clockwizer web flasher

Install a clockface on your ESP32 straight from the browser. No tools needed.

Choose a clockface
This browser can't talk to USB devices. Use Chrome or Edge on a computer. Installing needs a secure (HTTPS) page.

How it works

  1. Plug the ESP32 into your computer with a USB cable.
  2. Pick a clockface and press Connect and install. Choose the ESP32's serial port when asked.
  3. Wait for the install to finish. When it offers to connect the clock to WiFi, enter your 2.4 GHz network.
  4. Open the clock's settings page (http://clockwise.local, or scan the QR code on the display).

This writes the whole flash, partition table included, so it is also the way to move an older Clockwise to this firmware. After that the clock updates itself over WiFi, and you can switch clockface from its settings page.
